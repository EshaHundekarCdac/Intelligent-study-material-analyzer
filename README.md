# 📚 Intelligent Study Material Analyzer

An AI-powered NLP application built to process, analyze, and interact with study materials using intelligent workflows, web database tools, agentic routing, and voice features.

---

## 📌 Project Overview
The **Intelligent Study Material Analyzer** provides automated analysis of educational content. Utilizing NLP routing, agentic database querying, and multi-modal voice processing, it converts static learning materials into interactive search and analysis interfaces.

### Key Features
* **Modular Architecture:** Structured routes for agents, voice tools, state management, and workflows.
* **Agentic Workflows:** Dynamic routing and responder agents to handle study queries.
* **Database & URL Integration:** Custom table builders for dynamic study material indexing.
* **Multi-modal Capabilities:** Voice integration and study material state management.
